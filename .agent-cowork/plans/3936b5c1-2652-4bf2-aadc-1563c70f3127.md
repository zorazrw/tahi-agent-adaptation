# Plan: Create a presentation slide on LLMs

## Recommended approach
Create a single self-contained HTML slide that can be previewed directly in the app.

### What to build
- Add a new file: `llm_slide.html`
- Make it a polished 16:9 presentation slide focused on **Large Language Models (LLMs)**
- Keep all styling inline in the HTML so the file is portable and easy to preview/share

### Slide content
Use a concise one-slide narrative:
- Title: **Large Language Models**
- Subtitle: short plain-English framing, e.g. “How machines learn patterns in language at scale”
- 3 core idea blocks:
  - **What they are**: neural networks trained on massive text corpora
  - **How they work**: tokens → embeddings → transformer attention → next-token prediction
  - **Why they matter**: writing, coding, search, agents, and reasoning assistance
- Add a small bottom strip or side panel for **limits / caveats**:
  - hallucinations
  - bias
  - context limits
  - need for human oversight

### Design direction
Follow a strong, presentation-friendly aesthetic rather than a generic app page:
- dark editorial / futuristic theme
- oversized headline
- clean visual hierarchy
- subtle gradients / glow accents
- simple diagram flow for the pipeline
- large readable typography suitable for a projected slide

### Implementation notes
- Use semantic HTML and CSS only; avoid external dependencies
- Set the layout to a fixed slide canvas ratio (16:9 feel)
- Prefer a single-screen composition with no scrolling
- Ensure the file renders well inside the existing HTML preview renderer (`src/ui/components/file-renderers/HtmlRenderer.tsx`)

## Critical files
- Create: `llm_slide.html`

## Verification
- Open `llm_slide.html` in the app preview and confirm it renders as a single slide
- Check that the slide fits without vertical scrolling at normal preview size
- Confirm text is legible and visually balanced
- Confirm the HTML is self-contained and works without a separate CSS file
- Optionally open in a browser to verify portability outside the app
