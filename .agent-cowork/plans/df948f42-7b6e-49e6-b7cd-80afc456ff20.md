# Plan: Snake Trivia Game

## Understanding
- The repo already contains a standalone browser game in `snake-game/` with three files:
  - `snake-game/index.html`
  - `snake-game/style.css`
  - `snake-game/game.js`
- The current experience is a retro neon snake arcade game rendered on a `<canvas>`.
- For the request "make a trivia game about snakes," the cleanest approach is to repurpose this standalone mini-game into a themed trivia experience rather than touching the main Electron/React app.

## Recommended approach
- Replace the canvas-based snake gameplay with a browser trivia game themed around snakes.
- Keep the existing retro/arcade visual direction, but adapt the interface to quiz gameplay.
- Use a small in-file question bank in JavaScript so the game works without any backend.

## Implementation details
1. Update `snake-game/index.html`
   - Replace the game canvas and score HUD with trivia UI:
     - title/subtitle
     - progress indicator
     - score display
     - question card
     - multiple-choice answer buttons
     - feedback/status text
     - start screen and end screen with replay button
   - Preserve the existing single-page static structure so it remains easy to open directly in a browser.

2. Rewrite `snake-game/game.js`
   - Remove the snake movement/rendering loop logic.
   - Add a question dataset with snake-related facts and multiple-choice answers.
   - Implement trivia state management:
     - current question index
     - score
     - shuffled question order or randomized answers
     - selected/locked answer handling
     - next-question progression
     - final results summary and restart flow
   - Optionally include lightweight difficulty or streak messaging if it fits naturally.

3. Update `snake-game/style.css`
   - Retain the CRT/neon arcade theme, but restyle the layout around cards and answer buttons instead of a canvas.
   - Add clear visual states for:
     - idle answer buttons
     - hover/focus
     - correct answer
     - incorrect answer
     - disabled/locked state after answering
   - Ensure the layout is responsive and readable on smaller screens.

## Critical files
- `snake-game/index.html`
- `snake-game/style.css`
- `snake-game/game.js`

## Verification
- Open `snake-game/index.html` in a browser.
- Confirm the start screen appears and the quiz can begin.
- Answer several questions and verify:
  - score increments only on correct answers
  - feedback appears after each answer
  - inputs lock after selection until advancing
  - progress updates correctly
- Complete the full quiz and confirm the final score / replay flow works.
- Check the page on a narrow viewport to ensure controls remain usable and text does not overflow.
