# Plan: LLM Trivia Game

## Recommended approach
Build the trivia game as a standalone static experience in `llm-training/`, reusing its existing retro-futuristic visual style instead of changing the Electron/React app shell. This is the lowest-risk path because `llm-training/index.html` already references an `app.js` entry point and is isolated from the main app.

## Implementation
1. Replace the long educational page in `llm-training/index.html`
   - Convert it into a single-screen trivia layout with:
     - title / subtitle
     - score and progress HUD
     - question prompt
     - 4 multiple-choice answer buttons
     - feedback / explanation area
     - start state and final-results state
     - replay button
   - Keep the sci-fi / LLM-lab theme and background effects.

2. Rework `llm-training/styles.css`
   - Preserve the neon cyber aesthetic, scanlines, and animated background feel.
   - Remove section-scrolling/page-document styles that are no longer needed.
   - Add styles for quiz cards, answer states, disabled buttons, results summary, and responsive layout.

3. Create `llm-training/app.js`
   - Add an in-browser question bank about LLMs, covering topics like:
     - transformers
     - tokens / tokenization
     - embeddings
     - attention
     - context windows
     - fine-tuning vs pretraining
     - hallucinations / inference behavior
   - Implement quiz logic:
     - initialize / restart game
     - randomized question order and/or shuffled answers
     - score tracking
     - answer locking after selection
     - correct / incorrect feedback with brief explanation
     - next-question progression
     - final score summary and replay flow

## Critical files
- `llm-training/index.html`
- `llm-training/styles.css`
- `llm-training/app.js`

## Verification
- Open `llm-training/index.html` in a browser.
- Confirm the page loads without missing-script errors now that `app.js` exists.
- Start the quiz and verify:
  - questions render correctly
  - answer buttons respond once per question
  - score updates only for correct answers
  - progress indicator advances each round
  - feedback/explanations appear after answering
- Finish the quiz and confirm the final score and replay button reset the game cleanly.
- Check a narrow/mobile-sized viewport to ensure the layout remains readable and buttons stay usable.
