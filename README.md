## 🚀 Quick Start

Install [Bun](https://bun.sh/)
```bash
curl -fsSL https://bun.sh/install | bash
```

Clone the repository and install dependencies
```bash
git clone https://github.com/zorazrw/agent-cowork.git
cd agent-cowork
bun install
bun run dev
```
